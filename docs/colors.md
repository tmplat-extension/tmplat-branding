# Colors

This document contains the colors that are to be used when representing the tmplat brand.

1. [Palette](https://github.com/tmplat-extension/tmplat-branding/tree/main/docs/colors.md#palette)

## Palette

The following colors are recommended to be used:

| Color | Hex | RGB | CMYK |
| ----- | --- | --- | ---- |
| Ink | `#151A24` | 21, 26, 36 | 42, 28, 0, 86 |
| Ink Soft | `#4A5468` | 74, 84, 104 | 29, 19, 0, 59 |
| Paper | `#FFFFFF` | 255, 255, 255 | 0, 0, 0, 0 |
| Gradient Start | `#FF8A3D` | 255, 138, 61 | 0, 46, 76, 0 |
| Gradient End | `#F5544E` | 245, 84, 78 | 0, 66, 68, 4 |
| Solid Fallback | `#FF7A3D` | 255, 122, 61 | 0, 52, 76, 0 |

The gradient (`Gradient Start` &rarr; `Gradient End`) is used for the icon tile and banners, and is a warm nod to the legacy brown of the original "Template" brand. `Solid Fallback` should be used wherever a gradient isn't available.
